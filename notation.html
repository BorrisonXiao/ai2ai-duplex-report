Table 1. Notation version 2.0, maintained with the experiment plan.Scroll sideways on a narrow screen.

SymbolNameDefinition
\(N\)Number of distinct questionsN=105 for the main evaluation; alternative phrasings and reruns do not create extra cases.
\(e\)Evaluation case indexe is an integer from 1 to N; one case is one question, its earlier conversation audio, its recorded request and its checked reference answer, not one meeting (example: e=17 is the seventeenth question).
\(m\)Model identitym identifies a checkpoint and its inference mode from the selected model list (example: DuplexOmni S1 or Qwen3-30B Instruct); it is not an index for meetings.
\(\theta_m\)Frozen model weightsWeights of model m; record the checkpoint revision, precision, mode and decoding settings alongside every run.
\(p_{\theta_m}(\cdot\mid\cdot)\)Conditional output distributionThe distribution used to generate an output with model m given the inputs after the conditioning bar; sampling is denoted by the tilde symbol in the update equation.
\(v\)ASR/diarization pipeline choicev is D1 (Parakeet plus Nemotron diarization) or D2 (WhisperX plus pyannote); each produces its own words and speaker labels.
\(g\)Thinking-goal choiceg is an integer from 0 to 4, selecting Q0 summary, Q1 facts/events, Q2 people/tasks, Q3 checks/implications or Q4 combined goals.
\(g^\star\)Goal selected on development meetingsThe selected g for a given model and input type; freeze it before the final 105-question evaluation.
\(t\)Elapsed input timeTime in seconds from the start of the meeting audio supplied to this case; the injected request follows the available original conversation and no resumed future speech is included.
\(S_e\)Request onsetTime in seconds when the inserted user request begins for case e; earlier reasoning must use only audio/transcripts available before this time.
\(T_e\)Request endTime in seconds when the inserted user request ends; final answer inputs include the whole request through this time.
\(A_e(t),\ A_{e,\le t}\)Audio waveform and audio historyA_e(t) is the input waveform at time t; A_{e,≤t} is all input audio through t, including the inserted request when t reaches its end.
\(J_{m,e}\)Number of S1 input framesNumber of native frames for model m covering case e through the complete request; any required trailing silence is recorded separately.
\(j\)Native S1 frame indexj is an integer from 1 to J_{m,e}; frames are the small audio blocks accepted by model m, whose duration is model-specific (480 ms for the current DuplexOmni caller).
\(x_j^{(m)}\)Native S1 audio frameThe jth native audio frame for model m within the current case e; x_{1:J_{m,e}} means the full ordered frame sequence through request end.
\(K_e\)Number of earlier thinking chunksNumber of complete larger chunks available before S_e for case e; low-speech chunks are kept in history even when no model call is made.
\(i\)Larger thinking-chunk indexi is an integer from 1 to K_e; it counts the shared 10–40 second chunks, not native S1 frames or generated tokens.
\(t_i\)Thinking-chunk end timeEnd of chunk i in seconds, with t_0=0; a reusable earlier result must finish its input chunk before S_e.
\(X_i=A_e((t_{i-1},t_i])\)Audio in thinking chunk iThe samples after t_{i-1} through t_i; chunks regroup the same speech supplied to S1 without dropping or duplicating samples.
\(U_e^{\mathrm{aud}}\)Recorded user requestThe inserted spoken question for case e, beginning with the Assistant wake word; voice-enrollment clips are excluded from the model history.
\(U_e^{\mathrm{txt}}\)Exact text of the user requestThe text matching the chosen recorded question; append it to manual transcript history because the inserted request is absent from the original meeting transcript.
\(Y_{\le t}\)Ground-truth transcript through time tManual words, speaker labels and timestamps already available by t for this case; no future words from an unfinished utterance are included.
\(\widehat Y^{(v)}_{\le t}\)Generated transcript through time tWords, speaker labels and times from pipeline v using only the available audio; preserve released versions and do not apply future corrections early.
\(D_e\)Complete request-time input historyThe declared input for the condition: Y through T_e, generated Y through T_e or audio A through T_e; include the full spoken/text request.
\(D_{e,i}\)Input history through chunk iThe same input type as D_e, limited to t_i; this history contains no later user request.
\(Q^{(g)},\ Q_{\le i}^{(g)}\)Thinking instructionsQ^(g) is the selected instruction/goal family; Q_{≤i}^(g) is the sequence of instructions issued through chunk i, based only on earlier discussion.
\(q^{\mathrm{ans}}\)Common answer-format instructionThe same final-answer instruction is used in each paired condition and omitted from the probability formulas for readability.
\(h_i^{\mathrm{am}}\)Earlier native reasoning textReasoning text generated for chunk i when the model exposes a native thinking channel; absent channels remain N/A.
\(\mu_i\)Saved notesThe text saved after chunk i, such as facts, task owners, changed decisions or checked implications with source references; these notes are not spoken to participants.
\(z_i=(h_i^{\mathrm{am}},\mu_i)\)Result of an earlier thinking callThe optional native reasoning text and saved notes generated for chunk i; z_i is a result, whereas i is only an index.
\(Z_{<i}\)Results before chunk iThe ordered earlier results supplied to the next thinking call; record exactly which results survive any capacity fallback.
\(Z_e^{-}\)Earlier results available for the requestThe retained results generated from chunks ending before S_e; never include a result that used the current question.
\(h_e\)Native thinking for the actual requestNew native reasoning text generated after receiving the request, including any additional request-conditioned reasoning calls; earlier reasoning read again is input, not new thinking.
\(r_e\)Final answer textThe text answer returned for case e, kept separately from thinking text and control messages.
\(o_e\)Output speech waveformThe actual model speech played/saved for the response, excluding discarded synthesis and input speech.
\(R_e\)Native S1 responseThe response returned by S1; depending on the system it contains output speech o_e and optional native text r_e or control fields.
\(\widehat r_e\)Transcript of generated answer speechIndependent ASR applied to o_e for scoring; listen directly when words, names or numbers are disputed.
\(\alpha^{\mathrm{in}}_{m,j}\)Encoded input audioModel m’s audio representation for frame j, which may be continuous embeddings or discrete audio tokens; it is not a text thinking token.
\(\alpha^{\mathrm{out}}_{m,e}\)Output audio codesThe model-specific acoustic codes used to synthesize case e’s response; report them separately from text tokens.
\(\operatorname{Tok}_m(\cdot)\)Model m’s text tokenizationUse native generated token IDs where available; counts recovered by retokenizing text must be marked approximate. Vertical bars around a token sequence mean its number of tokens.
\(N_e^{\mathrm{think}}\)Request-time native thinking tokensNumber of new tokens in h_e; excludes earlier reasoning and answer text, with N/A for an absent channel and unavailable for an unexposed one.
\(N_e^{\mathrm{ans}}\)Request-time answer tokensNumber of newly generated final-answer text tokens in r_e.
\(N_e^{\mathrm{ctrl}}\)Request-time control tokensNumber of newly generated text control/protocol tokens, listed separately from answer and thinking tokens.
\(N_e^{\mathrm{am}}\)Amortized-thinking output tokensTotal text tokens generated by earlier calls: optional native reasoning and saved notes, including unhelpful updates; earlier input/prefill is counted separately.
\(N_e^{\mathrm{req,out}}\)All request-time text output tokensRecorded total of new request-time thinking, answer, helper and text control tokens; report directly if native thinking is unexposed.
\(N_e^{\mathrm{req,in}}\)Request-time input tokensAll text input tokens processed for the request, including earlier reasoning and notes read again; report audio positions separately.
\(N_e^{\mathrm{aux}}\)Other request-time generated textOutput from any declared request-time helper; the main plan uses deterministic history selection, so no helper is assumed.
\(r_e^\star\)Verified reference answerChecked answer based only on evidence available before this request; never an input to the evaluated system.
\(\mathcal F_e^\star\)Required answer factsThe source-supported facts, people, quantities and decision status needed for correctness; also record allowed alternatives and uncertainty.
\(a_e\)Complete-answer scorea_e=1 for a complete source-supported answer without a material unsupported claim; otherwise 0, including silence, missing output and capacity failure. Scoring must be finished before a final accuracy is reported.
\(\mathrm{Acc}_{105}\)Final accuracy over all 105 casesThe sum of complete-answer scores divided by 105; partial-run accuracy is labeled provisional and uses its own displayed reviewed-case denominator.
\(B\)Usable model input budgetThe model-specific number of input positions available after reserving output space; record text/audio position counts and memory constraints.
\(\mathcal S_B\)History-selection ruleA fixed rule selecting history and earlier results within budget B using only available inputs; never use reference facts, future speech or scoring labels.
\(D_e^B,\ Z_e^B\)History and earlier results retained after selectionThe selected inputs when full history does not fit; keep this condition distinct from full-history and model-native rolling context.
