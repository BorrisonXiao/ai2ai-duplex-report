# Full-Duplex-Bench v2 attribution

**Work:** Full-Duplex-Bench v2 task prompts (`prompts_staged_200.json`) and
evaluation prompts (`eval_prompts.json`).

**Authors:** Guan-Ting Lin, Shih-Yun Shan Kuan, Jiatong Shi, Kai-Wei Chang,
Siddhant Arora, Shinji Watanabe, and Hung-yi Lee.

**Paper:** “Full-Duplex-Bench-v2: A Multi-Turn Evaluation Framework for Duplex
Dialogue Systems with an Automated Examiner,” *Proceedings of the 64th Annual
Meeting of the Association for Computational Linguistics (Volume 2: Short
Papers)*, 2026, pages 27–36. [ACL Anthology](https://aclanthology.org/2026.acl-short.4/),
[DOI](https://doi.org/10.18653/v1/2026.acl-short.4).

**Source:** [Official Full-Duplex-Bench repository at commit
`3e799c45a045256f47d5f1c9cda90157e2d2ec9e`](https://github.com/DanielLin94144/Full-Duplex-Bench/tree/3e799c45a045256f47d5f1c9cda90157e2d2ec9e/v2).
The local files are byte-for-byte copies of the two prompt JSON files at this
revision. The source JSON is left unchanged, including its stale top-level note
that says 150 tasks and omits the Safety split; the actual prompt arrays contain
200 tasks across four splits.

**License:** The upstream repository's top-level `LICENSE` identifies the work
as [Creative Commons Attribution-NonCommercial 4.0 International (CC BY-NC
4.0)](https://creativecommons.org/licenses/by-nc/4.0/). The downloaded license
text and file checksums are recorded in the project workspace under
`data/benchmarks/full_duplex_bench_v2/`; the local data audit is published at
[`integrity.json`](integrity.json).

This website page contains an attributed summary, aggregate counts, and four
short scenario titles. It does not imply endorsement by the authors.
