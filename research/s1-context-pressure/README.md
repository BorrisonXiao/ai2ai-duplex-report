# S1 matched and context-pressure tests

- The original DailyTalk helper and new native runner match all 40 response-field records and spoken answer content.
- All 41 nested contexts produce speech; 20 retain the question meaning in ASR, with failures and later recoveries.
- None of the 11 contexts containing all source evidence gives a complete reference answer within the 19.2-second response window.

The protocol defines 41 independent nested audio suffixes, using sentence punctuation and merging overlapping sentences. Transcripts choose boundaries and score outputs; transcript words and speaker labels never enter model inputs. Native 480 ms packets are preserved, with zero padding only before the selected first boundary. All 12 request-speech packets are identical at every level. No future audio or S2 is supplied. The last level adds the original recording lead-in, which is not assumed to be silence. These diagnostic groups do not change the 10–40 second amortized-thinking chunk plan.

Request recognition and answer correctness are separate. The frozen strict ASR rule requires WER at most 0.25 and the exact key terms Assistant, shared folder and conceptual design. Additional Codex review allows understandable word forms while requiring both the folder-status question and missing conceptual-design files. This additional measure was introduced after seeing strict-rule false rejections; original scores remain unchanged. Neither measure proves internal comprehension. Source-answer checks use only the 11 prefixes with all listed evidence: recover folder placement and the identified components-design PowerPoint without material unsupported claims. Native text and independent Parakeet transcripts are reviewed separately. No human speech-quality rating is claimed. All levels are evaluated without assuming monotonic failure; capacity and format failures are separate.

The matched stage reproduces the earlier DailyTalk native helper, then compares native, quiet constrained and decode-and-clear runs at temperature zero, plus a sampled constrained control. The short engine context is 4,096 tokens; the executed pressure context is 49,152, with every selected audio/response turn retained and no trimming. Pressure uses constrained listening, preserves generated ASR, and requires a nonempty first reply at the known question end. This controlled start does not test autonomous wake-word timing. The model chooses all answer words. Forty silent input packets provide a 19.2-second response window on the input clock; this unpaced test has no real-time latency interpretation. Four levels still have speech text in their last captured packet. These are one-question diagnostics, not the full 105-question benchmark or a universal context limit.

Every executed primary job uses one H100 SXM 80 GB: Thinker, Talker, MTP and Code2Wav share GPU 0, then independent Parakeet ASR runs on GPU 0 after S1 exits. Matched qualification precedes four independent pressure workers, with no shared services and maximum four GPUs active. A later one-H100 80 GB fresh-session diagnostic uses Thinker only; it replays the exact native packet/response prompt twice, then clears earlier ASR fields in a third condition, and is not an additional pressure level or a spoken-answer evaluation. Allocation records include cancelled and failed startup attempts; the cancelled RTX request allocated zero GPUs. CPU review, plotting and publication use zero GPUs.
