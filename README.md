## Maintain the report

Current S2 pages are generated by `scripts/build_note_functions.py`; project checklist and log pages are generated by `scripts/build_project_progress.py`. Shared menus are defined in `scripts/site_navigation.py` and refreshed after page generation. Canonical public result data are in `research/note-functions/`; original study bundles and their source/license metadata remain with the corresponding pages.

Run `python scripts/validate_navigation.py` after rebuilding. Also validate HTML, figures, desktop/mobile rendering and the answer browser before publication. The workspace publication helper stages only the authorized report changes, preserves unrelated drafts, and verifies GitHub Pages after pushing.
