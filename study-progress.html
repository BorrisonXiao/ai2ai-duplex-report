First implementation: shared S1 evaluation

  • Extract the spoken answer from model-only playback and keep native model text separately.
  • Use verified answer facts and explicit reviews; keyword matches alone cannot certify correctness.
  • Count recorded native tokens separately and report missing channels or counts clearly.
  • Keep saved records when rerunning, and update progress after each example.

42 script checks pass. They cover silence, missing or partial outputs, capacity failures, unclear ASR, truncation, stale reviews, token counts and the full-question denominator. Those checks use labeled script fixtures; they are not new model outputs.
