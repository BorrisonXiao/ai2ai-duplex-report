How this batch works

Who does what? Codex selects sources, writes some questions and reviews the results. Local Qwen models generate the other questions and answer questions from transcripts as a quality check. The meeting assistant is the duplex model that would hear and answer the inserted question.

Earlier pilots depended heavily on Codex selecting evidence and writing comparison questions. This batch lets the local model work from the complete available transcript and generate up to three distinct questions at each cutoff. There is no question quota to fill when a useful request does not fit.

A retained question must sound like a plausible request from that participant and use earlier history. Its premise must be supported, and its evaluation reference must preserve any missing information or uncertainty. Codex checks source passages rather than accepting a model’s approval flag. The recent-minute control includes complete transcript excerpts whose start falls within the last 60 seconds; an excerpt crossing the start boundary is omitted. Multiple citations or failure under this limited context do not prove multi-hop reasoning. Generation and automated screening use the same model; independent human ratings remain a separate step.
