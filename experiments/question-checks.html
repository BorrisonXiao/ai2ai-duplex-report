What history lets the reader answer

One fixed Qwen3-30B-A3B-Instruct-2507 model ran through vLLM. Each question was tested with the same requester and text under four conditions. The reader never received the reference facts or selected answer evidence. The note writer received past speech and its own earlier notes; it was never given the test questions. “Recent” means complete transcript segments whose assumed release time falls in the last sixty seconds. Release time is the manual segment end plus 0.5 seconds; it is not measured ASR latency.

  • Full transcript with speakers. All causally available ground-truth transcript, with speaker fields.
  • Segments released in the last 60 seconds. Only segments released in the last 60 seconds, with speakers.
  • Full transcript without speaker fields. The identical full transcript with speaker fields removed; actual spoken names remain.
  • Automatic notes plus speech since the last update. Question-blind generated notes from fixed 120-second checkpoints plus all transcript released since the last checkpoint. Not a timing-matched or live-ASR result.

The no-speaker condition removes speaker fields, while retaining the same words, times and passage IDs. Names actually spoken in the meeting remain. The note condition uses question-blind updates every two source minutes, retaining up to 32 active records, plus all speech since its last checkpoint. Its recent span differs from the last-minute control, so this is a storage diagnostic rather than a fair timing experiment.

Codex used these criteria for every captured response:

  • Complete answer: Required answer facts are recovered without a material unsupported claim; a correct uncertainty answer is allowed for missing-information controls.
  • Incomplete or unsupported additions: Some required facts/qualifications are missing or unsupported extra claims weaken an otherwise useful answer.
  • Wrong main answer: Central fact, owner, decision state or number is wrong.
  • No earlier answer recovered: The output cannot recover an answer supported by the full source. This is often appropriate caution given restricted context, not necessarily a model error.

What the errors mean in context

A total-profit goal is not a per-unit margin

In ES2006a, C gives a €25 selling price, a €12.50 production-cost ceiling and a separate €50 million total-profit target. With full transcript history, the reader answers that the exact profit margin is €50 million. The source instead permits a conditional €12.50 per-unit surplus, 50% of the selling price, before unspecified other costs. A fluent answer and valid source IDs do not resolve this difference.

The person speaking is not automatically the requester

In TS3006c, A says they must record decisions in the final report. The no-speaker reader assigns that statement to requester B. The note condition names A and B even though its second cited acknowledgement is spoken by D. In another probe, the spoken introduction “my name is Maarika” survives removal of speaker fields, so the reader can still recover that person’s interface-design role. A speaker-field ablation is not the same as erasing every identity clue.

A rule can disappear before the question arrives

The EN2004a source tells annotators to choose one interpretation when two are equally plausible. The note writer never selects that rule. For the scrollwheel location in TS3004d, it does propose a useful left-side note, but changes the source quotation and fails the exact-quote check. These are different failures: choosing the wrong work versus losing a useful fact during note construction.

The first meeting-state prototype needs repair

The model produced 410 proposed note changes during 67 updates. Code checked that every quoted substring appeared in its cited, already available source and that a claimed speaker had cited speech. It retained 299 changes and left 111 unused: 110 had a quotation mismatch and three had unsupported speaker fields, with two changes having both kinds of problem. A quotation mismatch can be a changed capital letter or cleaned-up disfluency; it does not mean every rejected claim was factually false.

The current cache yields only four complete answers out of twenty. This is evidence against treating the first compact cache as ready; it is not evidence that structured memory can never help.

Before the speech comparison, the proposed repair is to copy source text by code, separate who spoke from who owns a task, preserve durable facts until they are contradicted, and check a claim’s meaning rather than only its quotation. These repairs are explicit gates in step 3, not unreported improvements to this captured run.
